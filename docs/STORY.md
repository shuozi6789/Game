# 故事与文案（供审核）

> 所有正文在 `scripts/game/narrative.gd`，本文件是摘要和设计意图，方便你只看这一页就能判断要不要改。

## 一句话

白色的小人一路往前走，遇见八个各有颜色的人（四组对立性格轴的两端）。每场对话里有三个选择，但没有任何一句「你是这样的人吗」：游戏从你的回答里读出倾向，悄悄决定要不要把对方的颜色留在你挂着的爱心流麻里。最后，流麻里的颜色组合决定他成了什么样的人。

---

## 八个人物（前五位是初版五人，后三位是本轮新增）

每个人物都有：一个**颜色**、一种**性格标签**、一个**没有说出口的心事**。
他们的性格不靠旁白解释，而是靠说话方式、在意的东西、以及**被你怎么回答时的反应**显出来。

### 红 · 阿燃（信使）
- 表面：声音大、坐不住、直接、不耐烦；喜欢先做再想。
- 内里：他等过一个不会来的人，还是把信跑完了。他相信「在路上」本身就是答案。
- 说话方式：短句、感叹、突然换话题、爱拍你肩膀。
- 看两段：
  - 「不知道才要走啊。」「知道去哪儿的人，走起来没这么好看。」
  - 「我送过一封信，走了三天。收信的人已经不在了。可我还是把信放在门口。你说，这算不算送到了？」
- 你喜欢「立刻出发」，他会当你自己人；你说「想清楚再走」，他反而认真看你一眼。

### 黄 · 阿衡（修表匠）
- 表面：慢、精确、爱纠正用词、好奇心重，有点书呆子。
- 内里：他用七年修一只永远慢四分钟的表；他父亲说「慢四分钟的表也是准的，只是准在另一个时间」。他不是修不好，是不舍得修好。
- 说话方式：先纠正概念，再提问；喜欢用「嗯」「不准确」；会记下你说的话。
- 看两段：
  - 「路没有尽头，只有下一个转弯。」
  - 「我修不好的东西，你替我带着。它慢四分钟。别调。」
- 你承认「非要弄明白才肯走」，他会把最珍贵的东西交给你；你不承认，他也不勉强，只说「表针走得很慢，我等得起」。

### 绿 · 阿禾（园丁）
- 表面：轻声、周到、先照顾别人，很少说自己的事。
- 内里：她为一个人种了三年的花，那个人没有来。她不说这件事，只是每天浇水。
- 说话方式：关心具体的小事（嘴干、脚累、花刚长出来），很少用大词。
- 看两段：
  - 「路不会跑掉，脚会。」
  - 「我没什么大道理。我只知道，花枯了要浇水，人要走了要送一送。」
- 你说「我坐一会儿」，她才慢慢讲自己的花；你说「我要赶路」，她说「那我给你装点水」——她不怪你，这才是她。

### 蓝 · 阿砚（守路人）
- 表面：话少、务实、不解释、命令式（「站住」「别走右边」）。
- 内里：他年轻时也想走，后来留下来守路。他把「该做的事」放在「想去的地方」前面，并不觉得自己伟大。
- 说话方式：短句、具体指令、很少用形容词；只在说「捡到人」时才露出情绪。
- 看两段：
  - 「我每年冬天都在右边捡到人。」
  - 「手很稳。你不是赶路的人。」
- 你帮他搬石头，他认你；你赶时间，他给你指路、提醒你天黑——他不会拦你，只会把该说的说完。

### 紫 · 阿遥（画者）
- 表面：梦游一样、说话像诗、不太管现实。
- 内里：他画一片没去过的远方，每天傍晚都差一点。他把孤独叫做「和天说话」。
- 说话方式：比喻、反问、突然在意颜色；不回答实际问题。
- 看两段：
  - 「我画了七年这片天。每天傍晚都不一样。总觉得差一点。就差一点。」
  - 「画下来，它就算去过一次。人总得先相信，才能走到。」
- 你说「天就快黑了」，他会说「黑之前，颜色最浓」；你说「像烧到边上的纸」，他会高兴，因为你说中了他要的。

## 对话结构

每个人物都是同一套骨架，但内容完全不同：

1. **开场 2–3 句**：他先注意到你（或先忙自己的事），你有一句内心独白。
2. **三个中途选择**：每个选择 2 个选项，不同回答触发**完全不同的回应段落**；每个选项带一个隐藏权重（+1 偏向这个人 / −1 不偏向）。
3. **两段过渡**：在三次选择之间各有一句带心事的细节（表、花、路、画、信）。
4. **结尾 2 句**：NPC 不再问你「是不是这样的人」，只是收束自己的话。
5. **静默判断**：对话结束时游戏把三个权重相加——正数就把 NPC 的颜色混进左上角的爱心流麻并播放取色，否则不变；随后用一句内心独白（「我没有说自己是，也没有说不是……」或「我没有伸手去接那一点红」）把结果交给你。整个过程没有一个是/否自问。

三段纯风景段落（晨光、溪畔、山顶）各有 3–4 句独白，没有选项，用来控制节奏。

## 你可能想改的地方

1. **人物味道**：现在每个人有一句「心事」压着，如果你觉得某个 NPC 还是太直白 / 太淡，可以在 `narrative.gd` 里加 1–2 句只属于他的细节（习惯、口癖、旧物）。
2. **结局标题**：标题我按「一种活法」来起名，如果你想要更朴素 / 更怪 / 更诗，直接改 `ENDINGS` 的 `title` 和 `lines`。
3. **三个选择的权重**：每个选择现在就是判断依据（+1 / −1）；如果你想让某一句更像「关键回答」（权重 2），或加一个中性回答（0），直接改 `NPCS` 里对应 option 的 `weight`。
4. **不出现自问**：新的判断逻辑在 `game.gd` 的 `_on_choice_made` / `_on_dialogue_finished`；结尾那句内心独白在 `Narrative.result_lines()`，想换语气改这里。
5. **长度**：现在每个 NPC 有三轮选择、约 14–18 屏文字，通关约 8–10 分钟。要更长可以给每个 NPC 加第 4 个选择点，或把 `_npc_score` 的阈值从 `>= 1` 调成 `>= 2`（更严格）。

## 本轮扩展：八色四轴

游戏结构参考 MBTI 的四个维度（两两对立），但不使用 MBTI 的名称与类型缩写，全部用自创中性词：

| 轴 | 一端 | 另一端 |
| --- | --- | --- |
| 能量 | 红 · 向外（热情直率） | 蓝 · 向内（冷静责任） |
| 判断 | 黄 · 讲理（理性求知） | 绿 · 讲情（温和共情） |
| 目光 | 紫 · 看向远方（浪漫理想） | 橙 · 看重脚下（务实当下） |
| 步调 | 青 · 守序（秩序计划） | 粉 · 随性（自由即兴） |

结局仍按取过的颜色集合给出（19 个手写结局 + 新组合自动生成），之后按空格打开
「性格画像」页：四行轴，标出你在每条轴上站在哪一边；两端都选是「两边都有」，
两端都没选是「还没有答案」。目标不是给玩家贴一个类型，而是让他看见自己一路
留下的倾向。

另外，八色后结局数量随之扩展：单色 8 个、双色 28 个、多色 3–8 种（3/4/5 有手写文本，
其余由 `ending_for()` 自动组合）。判断依据仍然是「取过的颜色集合」，而取色本身来自
每场对话三个选择的静默判断，不再有是/否自问。

### 橙 · 阿作（木匠）
- 表面：话少、手不停、只说眼前的事；不喜欢空谈。
- 内里：修不好就改成别的；他相信东西和人都是慢慢修出来的。
- 看一句：「我修了一辈子东西。坏了的，能修就修；修不好的，就改成别的。」

### 青 · 阿序（抄书人）
- 表面：守时、讲规矩、随身一本册子，习惯把一切都记下来。
- 内里：他父亲记了一辈子，却漏掉了自己那一页；他还在想该不该继续记。
- 看一句：「忘掉的东西不会自己回来。」

### 粉 · 阿游（放风筝的人）
- 表面：随性、爱笑、行囊里没有地图；她说风来了，路线就得改。
- 内里：没有方向时也会怕；怕就停下来看看风筝——它也不知道自己要去哪儿。
- 看一句：「风筝飞得高，是因为线一直没断。可线不能太紧，太紧它就掉了。」
